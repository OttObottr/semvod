# Independent benchmark review

An independent GPT-6 Astra agent checked the frozen Perception Test and QVHighlights evaluations without making inference calls or changing predictions, prompts, labels or production ranking.

For Perception Test, the review recomputed the first 20 hash-selected validation IDs and the five additional positive-cut IDs from the official 5,260-ID population. It verified the annotation archive and member hashes, the exact published gold subset, all 291 model-question comparisons and receipt amounts against the shared budget ledger. Results agree with the published summary: Gemini 61/97, OpenAI 54/97 and Jev 71/97. Jev's two invalid answers from one HTTP 400 count as wrong; the unknown charge remains separately reserved at $0.02. This is a QA capability audit with unequal audiovisual and sampled-frame inputs, not a SemVOD retrieval score. Public-data exposure and language priors remain uncontrolled.

For QVHighlights, the review verified the frozen protocol, inference source hashes at `d3536a0`, source media, extracted clips, every frame hash and exact query/gold coverage against the official annotation file. Independent interval-IoU calculations reproduced all six primary query scores and both checked-first scores. The two-query denominator retains the moderation blocks. The manual continuations attempted only the previously unattempted second query and preserved the blocks.

Review found that the Jev hybrid's reported reference cost included three reused OpenAI refinement receipts. Its $0.001905426 reference cost therefore differs from $0.001331426 in new paid-request cost; the $0.000574 difference is now explicit in the QVHighlights cost basis and narrative. The saved predictions and metrics were not rewritten. Shared refinements also mean the Jev arm is not an independent cold trial.

Neither dataset subset supports a general model ranking, representative creator-stream accuracy or measured per-hour cost. The QVHighlights ordering ablation produced no R@1 improvement, so this evidence does not justify changing production ranking. No remaining discrepancy was found in the checked selection, answer grading, interval metrics or recorded cost accounting after the replay distinction was documented.
